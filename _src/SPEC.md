# 写作规范（所有章节统一遵守）

这是给写作 Agent 的硬约束。违反任何一条，内容会被打回重写。

## 一、定位与语气

1. 读者是**普通成年男性**，25–40 岁，有工作，不傻，但吃过情感的亏。不要哄他，也不要审判他。
2. 语气：冷静、克制、像一个懂法律又懂人性的老友。**不喊口号，不煽动，不骂人，不做性别仇恨动员。**
3. 第二人称"你"。少用"我们男性"这种集体口号。多写"你在这件事上应该……"。
4. **关键立场（必须有，且要写得自然）**：剥削行为与性别无关，女性也会成为受害者；本站反对的是"利用信息差、情感依赖、法律盲区实施的剥削"，不是反对某个性别。这个立场在每篇至少出现一次，用一段话说清，不要说教。
5. 不写"渣女""女拳""捞女"之类的标签化词汇作为论述主体。要描述**行为**（"以结婚为条件反复索要大额财物""同时维持多条恋爱线以获取资源"），而不是给人贴标签。网络黑话可以在"术语表"里解释，但正文用中性表述。
6. 不提供任何违法建议：不教跟踪、不教装监控、不教入侵账号、不教暴力、不教敲诈。取证必须合法，这一点要反复强调后果。
7. 不写"保证追回""百分百胜诉"。法律有不确定性，要写清"取决于证据与裁判尺度"。

## 二、结构要求

- 文件是 **HTML 片段**，不要 `<html>/<head>/<body>`，不要 `<style>`，不要 `<script>`。
- 从 `<p>` 或 `<h2>` 直接开始。**不要写页面标题（h1）**，版式会自动生成。
- 每个 `<h2>` **必须有 id**，格式 `id="s2-1"`（篇号-节号），例如第二篇第 3 节 → `id="s2-3"`。
- 每个 `<h3>` **必须有 id**，格式 `id="s2-3-1"`。
- 一级节（h2）6–10 个；每个 h2 下面 800–1800 字；h3 用于细分，不要连续堆太多层级。
- 结尾加一节 `<h2 id="sX-99">本章要点</h2>`，用 `.callout--key` 罗列 6–8 条可执行结论。

## 三、可用组件（严格照抄标签结构，不要自创 class）

### 1. 案例卡（每篇 8–12 个）
```html
<div class="case">
  <div class="case-head"><span class="case-no">案例 2-1</span><span class="case-title">婚前给付 28 万彩礼，同居 4 个月后分手</span></div>
  <div class="case-body">
    <dl class="case-row"><dt>事实</dt><dd>……（150–300 字，写清时间线、金额、关键行为）</dd></dl>
    <dl class="case-row"><dt>争点</dt><dd>……</dd></dl>
    <dl class="case-row"><dt>裁判</dt><dd>……（写规则，不编案号）</dd></dl>
  </div>
  <div class="case-foot"><b>给你的启示：</b>……（一句可执行的话）</div>
</div>
```
> 注意：`dl` 里的 `dt/dd` 直接写在 `<dl class="case-row">` 内，不要包 div。

### 2. 法条块（每篇 6–10 个）
```html
<div class="law">
  <div class="law-head">《中华人民共和国民法典》第一千零四十二条</div>
  <div class="law-body">
    <p>禁止包办、买卖婚姻和其他干涉婚姻自由的行为。禁止借婚姻索取财物。</p>
    <cite>—— 这一条是主张"借婚姻索取财物"时的规范基础。</cite>
  </div>
</div>
```
只引用**确实存在**的条文。拿不准原文就写"条文主旨"并注明"（条文要旨）"，不要伪造原文。

### 3. 提示框（四种，按语义选）
```html

<div class="callout callout--key"><span class="callout-title">记住这句</span><p>……</p></div>
```

### 4. 表格

> 清单的勾选框与"已勾选 x/y"计数由 `main.js` 在运行时注入，**内容侧只写普通 `<ol><li>`**，不要手写 input 或额外 div。


## 四、数据与事实

- 引用统计数据必须给**可核查的来源口径**（如"国家统计局 2023 年《中国统计年鉴》""某省高院 2023 年婚姻家事审判白皮书"）。拿不到确切数字时，用**区间**或**趋势描述**，并写"公开报道中的常见区间"，不要编造精确到小数点的数字。
- 案例一律标注"匿名化改编"。**绝对不要编造案号**（如"(2021)苏04民终xxxx号"）。要体现权威性时写"最高人民法院 2024 年涉彩礼纠纷典型案例的裁判思路"。
- 涉及法条：民法典条文号要准确（1042、1043、1062、1063、1065、1066、1076、1077、1079、1087、1088、1089、1090、1091、1092、1093、1073、1165、1183、985、157）。司法解释：《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（一）》第 5 条；《最高人民法院关于审理涉彩礼纠纷案件适用法律若干问题的规定》（2024 年 2 月 1 日施行）。

## 五、长度

每篇目标 **12000–15000 个中文字**（不含标签）。宁可少一个案例，也不要写空话。每一段都必须给出：一个事实、一个判断、或一个动作。

## 六、交叉链接

正文中需要引用其他篇章时，用相对链接：`<a href="ch02.html">第二篇</a>`、`<a href="appendix.html">附录</a>`。不要用绝对路径。

## 七、输出

写到指定文件路径，UTF-8 无 BOM。写完后自检：`<h2>` 是否都有 id、组件标签是否闭合、是否出现 h1。
